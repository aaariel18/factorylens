## What to watch

The useful funnel is:

```text
referral → unique visitor → clone → star → issue/discussion → contributor
```

A post that produces fewer views but more clones/issues is often more valuable than a high-view post with no technical engagement.

## Rules

- never buy stars, followers, comments, clones, or traffic;
- keep promotional experiments distinguishable by date/channel;
- do not publish private referrer information or user-identifying data;
- record failures as well as wins;
- use GitHub **Insights → Traffic** as the source for repository traffic numbers.
