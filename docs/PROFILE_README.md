## Flagship project

### FactoryLens

**Open-source observability and black-box recording for machines that don't have APIs.**

FactoryLens explores how cameras, operator voice, machine signals, and event evidence can give legacy industrial machines a modern timeline without pretending they were designed for cloud-native telemetry.

Current CNC story:

```text
3-finger trigger
      ↓
operator voice note
      ↓
material + process metadata
      ↓
machine RUN / STOP
      ↓
pre-roll video + snapshots
      ↓
job evidence timeline
```

Repository: https://github.com/aaariel18/factorylens
