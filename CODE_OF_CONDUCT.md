# Community Code of Conduct

FactoryLens exists to make industrial software more open and approachable.

Be respectful, technical, and constructive. Critique ideas and implementations, not people. Welcome beginners, ask before sharing someone else's private information, and avoid harassment, threats, discrimination, or personal attacks.

Maintainers may edit or remove content, close discussions, or restrict participation when behavior repeatedly makes the project unsafe or unproductive.

For sensitive conduct concerns, contact the maintainer privately through an appropriate GitHub channel rather than posting personal information in a public issue.
